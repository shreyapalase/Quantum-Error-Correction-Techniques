Day04 — Quantum Error Correction Techniques: Five-Qubit Quantum Error-Correcting Code [[5,1,3]]
1. Introduction

Quantum information is extremely sensitive to noise and environmental disturbances.

Unlike a classical bit, a qubit can exist in a superposition of states:

∣ψ⟩=α∣0⟩+β∣1⟩

where

∣α∣2+∣β∣2=1

During quantum computation, a qubit may interact with its environment and experience errors.

The three fundamental single-qubit Pauli errors are:

X=(0110)

Y=(0−ii0)

Z=(100−1)

These errors are interpreted as:

    $X$: bit-flip error

    $Z$: phase-flip error

    $Y$: simultaneous bit- and phase-flip error

The five-qubit quantum error-correcting code, denoted by [[5,1,3]], is the smallest quantum error-correcting code that can correct an arbitrary error affecting any one physical qubit.

The code encodes one logical qubit into five physical qubits and uses stabilizer measurements to identify and correct errors without directly measuring the logical quantum information.
2. Why Is a Five-Qubit Code Needed?
2.1 General Single-Qubit Error

An arbitrary error acting on one qubit can be expressed as a linear combination of the Pauli operators:

E=aI+bX+cY+dZ

where

I=(1001)

is the identity operation.

Therefore, if a quantum error-correcting code can correct $X$, $Y$, and $Z$ errors on any one physical qubit, it can correct an arbitrary single-qubit error.

This follows from the linearity of quantum mechanics.
2.2 Why a Single Physical Qubit Is Insufficient

Suppose the original qubit is

∣ψ⟩=α∣0⟩+β∣1⟩

If an $X$ error occurs:

X∣ψ⟩=α∣1⟩+β∣0⟩

For a $Z$ error:

Z∣ψ⟩=α∣0⟩−β∣1⟩

For a $Y$ error:

Y∣ψ⟩=i(α∣1⟩−β∣0⟩)

If we directly measure the qubit to determine which error occurred, the measurement would generally disturb the quantum information.

Therefore, quantum error correction must determine the error indirectly.

The solution is to encode the logical qubit into multiple physical qubits.
3. Meaning of [[5,1,3]]

The notation [[n,k,d]] describes a quantum error-correcting code.

For the five-qubit code:

[[5,1,3]]

the parameters have the following meaning:
Parameter	Meaning
$n=5$	Number of physical qubits
$k=1$	Number of logical qubits
$d=3$	Code distance

Therefore,

5 physical qubits→1 logical qubit

The code has distance

d=3

The number of errors that can be guaranteed to be corrected is

t=⌊d−12⌋

For $d=3$:

t=⌊3−12⌋=1

Therefore:

    The five-qubit code can correct any single-qubit error.

4. Encoding One Logical Qubit into Five Physical Qubits

The original logical state is

∣ψ⟩=α∣0⟩+β∣1⟩

An encoding operation $U_{\mathrm{enc}}$ transforms the state into a five-qubit encoded state:

Uenc(∣ψ⟩∣0000⟩)=∣ψL⟩

The encoded state has the form

∣ψL⟩=α∣0L⟩+β∣1L⟩

where $|0_L\rangle$ and $|1_L\rangle$ are the logical codewords.

The five physical qubits are not simply five copies of the original qubit.

In general,

∣ψL⟩≠∣ψ⟩⊗5

Instead, the quantum information is distributed over an entangled five-qubit code space.
5. Logical Codewords

One standard representation of the five-qubit code is:

∣0L⟩=14(∣00000⟩+∣10010⟩+∣01001⟩+∣10100⟩+∣01010⟩−∣11011⟩−∣00110⟩−∣11000⟩−∣11101⟩−∣00011⟩−∣11110⟩−∣01111⟩−∣10001⟩−∣01100⟩−∣10111⟩+∣01101⟩)

The logical $|1\rangle$ state can be obtained by applying the logical $X$ operator:

∣1L⟩=X‾∣0L⟩

The arbitrary encoded state is therefore

∣ψL⟩=α∣0L⟩+β∣1L⟩

    Note: Different conventions may use different qubit orderings or equivalent representations of these codewords. The underlying code properties remain the same.

6. Stabilizer Formalism

The five-qubit code is most conveniently described using stabilizers.

A stabilizer is an operator $S$ for which every valid code state satisfies

S∣ψL⟩=∣ψL⟩

A standard set of four independent stabilizer generators is:

S1=XZZXI

S2=IXZZX

S3=XIXZZ

S4=ZXIXZ

The complete stabilizer group is generated by these operators:

S=⟨XZZXI, IXZZX, XIXZZ, ZXIXZ⟩

The symbol $I$ represents the identity operation on the corresponding qubit.
7. Why Are There Four Stabilizers?

For an $n$-qubit stabilizer code with $r$ independent stabilizer generators, the number of logical qubits is

k=n−r

For the five-qubit code:

n=5,r=4

Therefore,

k=5−4=1

Hence, the code contains one logical qubit.

The dimension of the code space is

2k=21=2

The full five-qubit Hilbert space has dimension

25=32

Thus, the four stabilizers reduce the relevant Hilbert space from

32→2

dimensions.
8. Stabilizer Eigenvalues

For a valid encoded state,

Si∣ψL⟩=∣ψL⟩

Therefore, if there is no error, measuring every stabilizer produces the eigenvalue

+1

The no-error result is therefore:

(+1,+1,+1,+1)

The eigenvalues can be represented as binary syndrome bits:

+1→0

−1→1

Therefore, the no-error syndrome is:

0000
9. How Errors Change the Stabilizer Measurements

Suppose an error $E$ occurs.

There are two possibilities when comparing $E$ with a stabilizer $S_i$.
Commuting Case

If

ESi=SiE

then the error commutes with the stabilizer.

The stabilizer measurement remains $+1$.
Anticommuting Case

If

ESi=−SiE

then the error anticommutes with the stabilizer.

The stabilizer eigenvalue changes from $+1$ to $-1$.

Therefore:

Syndrome bit=1if the error anticommutes with the stabilizer

This commutation/anticommutation property is the fundamental mechanism of syndrome-based quantum error correction.
10. Syndrome Measurement

The four stabilizers produce four binary measurement results:

s1s2s3s4

The four-bit string is called the syndrome.

For no error:

0000

For a particular single-qubit error, the syndrome is different.

The syndrome does not reveal $\alpha$ or $\beta$.

Instead, it provides information about the error that occurred.

This allows the error to be identified without directly measuring the logical state.
11. Why Four Syndrome Bits Are Required

There are five possible locations for an error.

For each location, there are three non-identity Pauli errors:

X,Y,Z

Therefore, the total number of possible single-qubit Pauli errors is:

5×3=15

Including the no-error case gives:

1+15=16

Four binary syndrome bits can represent:

24=16

different values.

Therefore:

24=16=1+3(5)

which matches the number of no-error and single-qubit Pauli-error cases.

13. Hand Calculation: $X_4$ Error

Consider an error:

E=X4

The stabilizers are:

S1=XZZXI

S2=IXZZX

S3=XIXZZ

S4=ZXIXZ

Now examine the fourth position in each stabilizer:
Stabilizer	Qubit 4	Relation with $X_4$
$S_1$	$X$	Commutes
$S_2$	$Z$	Anticommutes
$S_3$	$Z$	Anticommutes
$S_4$	$X$	Commutes

Therefore, the stabilizer eigenvalues become:

(+1,−1,−1,+1)

Converting

+1→0,−1→1

gives:

0110

Therefore:

0110→X4

The correction operation is:

X4

Since

X4X4=I

we obtain:

X4X4∣ψL⟩=∣ψL⟩

Therefore, the original encoded state is recovered.
14. Hand Calculation: $Y_3$ Error

Now consider:

E=Y3

The Pauli operators satisfy:

Y=iXZ

Ignoring the overall phase $i$, the syndrome of $Y_3$ can be obtained from the syndromes of $X_3$ and $Z_3$.

From the syndrome table:

X3→1100

and

Z3→0010

The syndrome is obtained by binary addition modulo $2$:

1100⊕0010=1110

Therefore:

Y3→1110

If the measured syndrome is

1110

the decoder identifies the error as $Y_3$.

The correction is therefore:

Y3

Because

Y32=I

we obtain:

Y3Y3∣ψL⟩=∣ψL⟩

Thus, the encoded state is restored.
15. Hand Calculation: $Z_2$ Error

Consider the error:

E=Z2

The second position of the stabilizers is:
Stabilizer	Qubit 2
$S_1$	$Z$
$S_2$	$X$
$S_3$	$I$
$S_4$	$X$

The $Z$ error commutes with $Z$ and $I$, but anticommutes with $X$.

Therefore:

S1:+1

S2:−1

S3:+1

S4:−1

Hence:

(+1,−1,+1,−1)

corresponds to:

0101

Therefore:

0101→Z2

The required correction is:

Z2
16. Correction Principle

Suppose the encoded state is:

∣ψL⟩

and an error $E$ occurs.

The resulting state is:

∣ψL′⟩=E∣ψL⟩

The syndrome identifies the error.

For a Pauli error, the correction operator can be chosen as the same Pauli operator:

C=E

The corrected state becomes:

C∣ψL′⟩=CE∣ψL⟩

Since every Pauli operator satisfies:

E2=I

we obtain:

CE=E2=I

and therefore:

C∣ψL′⟩=∣ψL⟩

The original encoded state is recovered.

    Note: More generally, error correction only needs $CE$ to act as the identity on the code space, possibly up to an irrelevant global phase.

17. Why the Logical Information Is Preserved

The purpose of syndrome measurement is not to measure the logical qubit directly.

The logical state is:

∣ψL⟩=α∣0L⟩+β∣1L⟩

The stabilizers have the same eigenvalue for every state in the code space:

Si∣ψL⟩=∣ψL⟩

Therefore, stabilizer measurements do not distinguish between:

∣0L⟩

and

∣1L⟩

They only determine which error subspace the state occupies.

Consequently, the logical amplitudes $\alpha$ and $\beta$ are preserved.

This is one of the most important differences between quantum error correction and ordinary measurement-based error detection.
18. Logical Pauli Operators

The logical Pauli operators act on the encoded qubit.

A standard choice is:

X‾=XXXXX

and

Z‾=ZZZZZ

They act on the logical states as:

X‾∣0L⟩=∣1L⟩

X‾∣1L⟩=∣0L⟩

and

Z‾∣0L⟩=∣0L⟩

Z‾∣1L⟩=−∣1L⟩

Therefore, the encoded qubit obeys the same logical Pauli algebra as an ordinary physical qubit.
19. Code Distance

The distance of the code is:

d=3

The distance determines the minimum weight of a Pauli operator that acts nontrivially on the logical information while preserving the code space.

For a code with distance $d$:

t=⌊d−12⌋

errors can be corrected.

For the five-qubit code:

t=⌊3−12⌋=1

Therefore:

    Any one-qubit error can be corrected.

    The code does not guarantee correction of arbitrary two-qubit errors.

20. Error Detection Versus Error Correction

These two concepts should be distinguished.
Error Detection

The syndrome indicates whether the state has left the code space.

For example:

0000

is the no-error syndrome in the single-error model.

A non-zero syndrome indicates an error within the set of correctable single-qubit Pauli errors.
Error Correction

The syndrome is mapped to a particular correction operation.

For example:

0110→X4

Therefore:

Syndrome→Error identification→Correction
21. Why the Code Can Correct a General Quantum Error

Consider a general error acting on physical qubit $i$:

Ei=aI+bXi+cYi+dZi

The encoded state becomes:

Ei∣ψL⟩=a∣ψL⟩+bXi∣ψL⟩+cYi∣ψL⟩+dZi∣ψL⟩

The syndrome measurement separates these components into different syndrome subspaces.

The four possibilities are:

Ii,Xi,Yi,Zi

The correction procedure then removes the corresponding error.

Therefore, although the physical error may be a general quantum operation, it is sufficient to correct its Pauli components.

This is known as the Pauli error basis.
22. Perfect-Code Property

The five-qubit code is a perfect quantum error-correcting code because the quantum Hamming bound is saturated for correction of arbitrary single-qubit errors.

The number of available syndromes is:

2n−k=25−1=16

The number of correctable cases is:

1+3n=1+3(5)=16

Therefore:

25−1=1+3(5)=16

Every single-qubit Pauli error can therefore be assigned a unique syndrome.
23. Complete Error-Correction Process

The five-qubit code operates according to the following sequence:

∣ψ⟩→∣ψL⟩→E∣ψL⟩→Syndrome measurement→Error identification→Correction→∣ψL⟩→∣ψ⟩
Step 1: Prepare the Logical State

∣ψ⟩=α∣0⟩+β∣1⟩
Step 2: Encode

∣ψ⟩→∣ψL⟩
Step 3: Error Occurs

For example:

∣ψL⟩→X4∣ψL⟩
Step 4: Measure Stabilizers

The syndrome is obtained:

0110
Step 5: Identify the Error

From the syndrome table:

0110→X4
Step 6: Apply Correction

Apply:

X4
Step 7: Recover Encoded State

X4X4∣ψL⟩=∣ψL⟩
Step 8: Decode

The inverse encoding operation gives:

Uenc†∣ψL⟩=∣ψ⟩∣0000⟩
Step 9: Measure the Logical Qubit

The final measurement can be compared with the expected logical state.
24. Final Measurement and Comparison

Suppose the intended logical state is:

∣ψ⟩=α∣0⟩+β∣1⟩

After successful error correction and decoding, the output should be:

∣ψout⟩=α∣0⟩+β∣1⟩

The theoretical measurement probabilities in the computational basis are:

P(0)=∣α∣2

and

P(1)=∣β∣2

Therefore:

P(0)=∣α∣2,P(1)=∣β∣2

The measured output distribution should approach these probabilities over many experimental shots.
25. Example: Logical $|0\rangle$

For the intended state:

∣ψ⟩=∣0⟩

we have:

α=1,β=0

Therefore:

P(0)=1

and

P(1)=0

After successful correction:

∣ψout⟩=∣0⟩
26. Example: Logical $|1\rangle$

For:

∣ψ⟩=∣1⟩

we have:

α=0,β=1

Therefore:

P(0)=0

and

P(1)=1

After successful correction:

∣ψout⟩=∣1⟩
27. Example: Logical $|+\rangle$

Consider:

∣+⟩=∣0⟩+∣1⟩2

Here:

α=12,β=12

Therefore:

P(0)=∣12∣2=12

and:

P(1)=∣12∣2=12

Hence, after successful correction and measurement in the computational basis:

P(0)=P(1)=12

This example also demonstrates why preserving quantum phase information is important. Measuring only in the computational basis does not completely characterize an arbitrary quantum state.
28. Fidelity of the Recovered State

The quality of state recovery can be quantified using fidelity.

For pure target and output states:

F=∣⟨ψtarget∣ψoutput⟩∣2

where:

    $|\psi_{\mathrm{target}}\rangle$ is the intended logical state.

    $|\psi_{\mathrm{output}}\rangle$ is the recovered logical state.

If:

∣ψoutput⟩=∣ψtarget⟩

then:

F=1

Therefore, $F=1$ represents perfect state recovery.

For an ideal simulation containing only one deliberately introduced correctable Pauli error, perfect recovery is expected.

In real hardware, the fidelity can be lower because of additional physical noise and imperfections.
29. Syndrome Table as a Decoder

The syndrome table acts as a decoder.

Mathematically, the decoding process can be represented as:

D:{0,1}4→{I,Xi,Yi,Zi}

For example:

D(0000)=I

D(0110)=X4

D(0010)=Z3

D(1110)=Y3

The correction operation is then selected from the decoded error.
30. Important Properties of the Five-Qubit Code

The major properties of the code are:

    It encodes one logical qubit.

    It uses five physical qubits.

    It has distance three.

    It can correct any arbitrary single-qubit error.

    It has four independent stabilizer generators.

    It has sixteen possible syndrome values.

    Every single-qubit Pauli error has a unique syndrome.

    The logical information is encoded nonlocally.

    Syndrome measurements do not directly measure the logical state.

    It is a perfect quantum error-correcting code.

31. Limitations

Although the five-qubit code corrects arbitrary single-qubit errors, it does not guarantee correction of arbitrary errors on two or more qubits.

For example, if two physical qubits experience errors simultaneously, the resulting error may have the same syndrome as a correctable single-qubit error.

The decoder may then apply the wrong correction.

Therefore:

[[5,1,3]]

guarantees correction of one-qubit errors, not arbitrary multiple errors.

In practical quantum systems, additional sources of error include:

    Gate imperfections

    Measurement errors

    Qubit relaxation

    Qubit dephasing

    Unwanted qubit interactions

    Errors during syndrome extraction

Thus, experimental performance can differ from the ideal theoretical result.
32. Conceptual Overview

The complete operation of the five-qubit code can be summarized as:

Logical qubit→Encoding→Five physical qubits

followed by:

Single-qubit error→Syndrome measurement→Error identification

and finally:

Correction→Decoding→Recovered logical qubit

The key idea is that error information is extracted without directly measuring the logical information.

34. Conclusion

The five-qubit quantum error-correcting code is represented by:

[[5,1,3]]

It encodes one logical qubit into five physical qubits and protects the logical information against any arbitrary single-qubit error.

The four stabilizer generators are:

XZZXI,IXZZX,XIXZZ,ZXIXZ

These four stabilizers generate a four-bit syndrome.

Because:

24=16

and:

1+3(5)=16

there is a unique syndrome for every no-error or single-qubit Pauli-error case.

The essential principle is:

Error→Syndrome→Identification→Correction

For example:

X4→0110→X4

and:

Y3→1110→Y3

After applying the appropriate correction:

CE∣ψL⟩=∣ψL⟩

Finally, decoding returns the logical state:

Uenc†∣ψL⟩=∣ψ⟩∣0000⟩

Therefore, the five-qubit code demonstrates the fundamental principle of quantum error correction:

    Quantum information can be protected against single-qubit errors without directly measuring or destroying the logical quantum state.
